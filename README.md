### North Carolina International Tree Ring Database (ITRDB) Data

This map displays all tree ring datasets located in North Carolina that publicly available through the International Tree Ring Database (ITRDB), as well as the Climatic Divisions of North Carolina. Tree ring datasets are classified by Genus and display the ITRDB ID, Principal Investigator, and species code for each dataset marker upon click. Any Genus with 3 or fewer datasets available were classified as "Other". Climatic Divisions are classified by region (Mountains, Piedmont, Coastal).

Note that the species code is typically the first 2 letters of the Genus and Species (i.e. QUAL = Quercus alba, PIPA = Pinus palustris Mill. etc.). Codes may differ from this convention for species within the same genus with the same starting letters for the species name (i.e. TSCA = Tsuga Canadensis, TSCR = Tsuga Caroliniana).

#### Data Attribution:
Basemap provided by Leaflet and StadiaMaps

U.S. Climate Division polygon data were obtained from NOAA Physical Science Laboratory and were subset to North Carolina in ArcGIS Pro. Polygons were simplified using the Simplify Polygon tool in ArcGIS Pro using the Douglas-Peuker method with the tolerance set to 1 U.S. Survey Mile. Exported shapefile was converted into a GeoJSON using geojson.io

Tree Ring data points were manually created in Google MyMaps using available information from the International Tree Ring Database through the National Centers for Environmental Information Paleo Data Search. Exported KML file from Google MyMaps was converted into a GeoJSON using geojson.io

Tree icons obtained from FontAwesome.
